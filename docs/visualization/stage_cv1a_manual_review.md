# Stage C.V1A：太阳电池减反膜视觉原型人工复核

## 1. 复核对象与方法

对象：`app_solar_cell_ar` 的现有 Vite/Three.js 页面。

方法：

1. Playwright 启动真实 Chromium，执行 `stage_cv1a_visual_runtime.spec.js`；
2. 分别切换等轴剖视、侧面剖视、光路视角和 TE/TM，保存五张全页截图；
3. 在 Codex 应用内浏览器再次打开同一 localhost 页面，检查 DOM、按钮行为、HUD 和浏览器 console；
4. 单元测试校验材料颜色、厚度映射、相机预设和层交互外观；
5. 不使用截图像素完全一致作为判据。

## 2. 人工检查清单

| 项目 | 结果 | 复核说明 |
|---|---|---|
| 背景 | 通过 | 场景和 solar 页面主题均为暖白浅灰；无黑色科幻背景、霓虹或 bloom |
| 材料颜色 | 通过 | SiO2 灰蓝、TiO2 米灰、MgF2 灰绿、Si 深灰蓝；低饱和且跨刷新稳定 |
| 层序 | 通过 | Air 仅作语义；可见结构严格为 SiO2 → TiO2 → MgF2 → Si，膜层固定三层 |
| 厚度表现 | 通过 | 三层无默认间隙或重叠；基底明显更厚；真实厚度在标签中，页面声明视觉放大 |
| 相机 | 通过 | 默认等轴剖视完整显示膜面、侧面层序和基底；侧面/光路预设有效；重置返回等轴剖视 |
| 灯光 | 通过 | 柔和半球光、单主方向光和弱环境补光；边界主要由描边识别，无强阴影/HDR 高光 |
| 波形 | 通过 | 细线、低饱和固定语义色和方向箭头；TE/TM 可见变化；播放/暂停保持；HUD 明确“教学示意波” |
| 标签 | 通过 | 显示三层层号、材料、四位小数真实厚度、当前波长和偏振；不把教学波称为定量场 |
| 交互 | 通过 | 自动测试确认膜层点击保持选中、空白取消、案例切换清空；hover/selected 外观由公共模块管理 |
| 已知限制 | 接受 | 见下节；不影响本阶段原型边界 |

## 4. 行为与回归检查

自动化检查覆盖：

- 颜色映射稳定、未知材料哈希稳定、介质 metalness 为 0；
- 厚度映射单调、有上下界；
- 三个相机预设有效且没有 TOP_VIEW；
- 重置视角返回 `ISOMETRIC_SECTION`；
- 三层 mesh 可加载，选中/取消有效；
- 动态波持续播放，暂停后时间停止，恢复后继续；
- renderer 实例数保持 1，案例切换不触发 context loss；
- 从 solar 切换至 WDM 再返回后选择为空；
- 页面 console 和 page error 均为空；
- 原 R/T 选点振幅、TE/TM 正交基和波生命周期测试继续通过。

## 5. 已知限制

1. 原型只作用于 `app_solar_cell_ar`；其他案例尚未统一到公共视觉模块。
2. `LineBasicMaterial.linewidth` 在部分 WebGL 平台固定为 1 像素；当前设计以颜色、透明度和方向箭头保证可读性。
3. 厚度为非线性视觉映射，不能从屏幕比例反推纳米厚度；真实值以标签为准。
4. “展开/叠合”会引入教学性的视觉间距，默认叠合状态没有真实间隙。
5. 动态波仍是选中光谱点 R/T 驱动的教学示意，不是空间定量电场。
6. 当前右侧旧参数面板的“波长”字段仍沿用既有错误绑定并显示角度；Stage C.V1A 未实施 Workspace/参数面板重构，原型 HUD 已单独显示正确当前波长。
7. 当前正式工程 JSON 只有现有离线光谱切片；前端没有新增角度计算、热力图或场求解。

## 6. 人工结论

Stage C.V1A 已达到“低饱和蓝灰白、浅色学术科研可视化、层序清晰、视觉克制”的原型目标，并守住正式结构、物理绑定、renderer 和资源生命周期边界。建议下一步由人工在桌面浏览器打开 `/?case=app_solar_cell_ar`，重点感受三种相机视角、标签遮挡和 hover/selected 强度；未获人工确认前不推广到其他案例。
